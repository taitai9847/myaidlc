## When to choose

New behavior added to an existing project: a new screen, endpoint, command, option, or integration. Choose it when what to build still needs requirements and a plan, or when the change spans more than one part of the code.

## Route

All 10 stages. Inception turns the intent into requirements and a plan, split into units; Construction designs, plans and builds each unit in turn, then runs the project's checks once.

## Approvals

Intent, requirements, the delivery plan, each unit's code plan and checkpoint, the test results, and the handoff. Document reviews run at the end of Ideation and Inception and on each code plan; a code review runs on each unit and on any fix made while testing.
